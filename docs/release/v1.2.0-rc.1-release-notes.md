## Compatibility and recovery

- Project data remains local-first; no user project data was modified during verification.
- Upgrade rehearsal covers pre-migration backup, migration failure recovery, and
  rollback using a disposable copy (Sprint 112.27–112.29).
- Do not upgrade the source project without creating a verified backup first.
- If migration fails, preserve the original source and restore only through the
  recovery flow. Emergency backup is created automatically before restore.
- Interrupted import/export processes support two-phase rollback with sentinel claims
  (run318–run322 pattern).

## Privacy

- Reader/share output redacts protected content and drops internal metadata (SpoilerSafeExportService).
- Cross-workspace access requires explicit permissions and links.
- Do not place credentials in project content or manifests.
- External endpoint, encrypted-at-rest, and OS sandbox certification are not
  claimed by this release candidate.
- AI generation records and API keys are never persisted to the project database.

## Known limitations

- Linux artifact is a debug bundle packaged for local rehearsal, not a production
  distribution package.
- Web is built in release mode; Android artifact is debug mode for local rehearsal.
  Windows/macOS/iOS release artifacts are not included in this RC.
- Performance results are development-only benchmarks, not production SLOs.
- E2E evidence is an in-process contract flow; native desktop and OS-level
  certification remain separate work.
- Native assistive-technology certification and physical display contrast
  measurement remain deferred.
- Hosted CI and public release publication remain explicit approval gates.
- True hardware power-loss recovery and USB cold-eject verification require
  hands-on testing with Choirudin on real hardware.
- Native crash-dump dialog and recovery prompt are UNVERIFIABLE from cron;
  crash diagnostics are proven via structured log tests only.
- Profile-mode FrameTiming is not captured by local test gates.

## Feature flags

local validation; a flag being known does not imply it is enabled.
