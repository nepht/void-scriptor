## Versi panjang (forum, grup WhatsApp/Discord, komunitas menulis)

**Dicari: 5-20 novelis untuk menguji aplikasi menulis novel baru**

Halo! Kami sedang mengembangkan **Void Scriptor** — aplikasi desktop untuk
menulis novel dan membangun dunia cerita (Windows, berjalan lokal, tanpa akun,
naskah tidak dikirim ke mana pun). Kami mencari novelis untuk mencoba versi
awalnya dan memberi masukan jujur.

**Yang akan kamu lakukan:**
- Satu sesi individual 60-90 menit, online bareng fasilitator.
- Mengerjakan tugas menulis sederhana: mulai novel, buat karakter, menulis
  paragraf, cari catatan lore, ekspor, backup/restore.
- Cerita apa yang kamu tulis di sesi itu bebas; naskah pribadimu tidak diminta.

**Yang perlu kamu tahu (jujur):**
- Produk masih versi awal (alpha). Fitur cloud, kolaborasi, dan publishing
  sengaja belum aktif.
- Sesi direkam layar hanya jika kamu setuju; rekaman hanya untuk evaluasi,
  bisa kamu minta hapus kapan saja.
- Bug dan hal membingungkan justru data berharga — kamu tidak dinilai.
- Tidak ada hadiah berbasis penyelesaian tugas. [ISI: bila ada apresiasi
  tetap, sebutkan di sini; bila tidak ada, hapus baris ini]
- Nama kamu disamarkan (P01, P02, ...) di semua catatan.

**Syarat:** rutin menulis (novel panjang maupun cerpen), punya laptop Windows,
belum pernah memakai Void Scriptor sebelumnya.
