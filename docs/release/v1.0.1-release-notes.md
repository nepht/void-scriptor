# Void Scriptor v1.0.1

## Status

Stable patch release. Dipromosikan dari `v1.0.1-rc.1` tanpa perubahan kode
tambahan pada area hotfix; commit final hanya menaikkan versi ke `1.0.1+1`
dan memfinalisasi catatan ini.

## Ringkasan

Patch release untuk stabilisasi startup, crash diagnostics lokal, dan
startup recovery.

## Perubahan

- Menambahkan crash diagnostics lokal dengan redaksi secret.
- Menambahkan startup recovery policy: normal → safe → recovery.
- Menambahkan `RecoveryShell` untuk boot failure.
- Menambahkan reset configuration pada recovery mode.
- Mematuhi persisted startup decision saat boot.
- Memperbaiki Material environment pada recovery composition root agar
  `RecoveryShell` memiliki `Directionality` dan `Theme` yang valid.
- Menambahkan security dan privacy review untuk hotfix.

distribution channel produksi. Langkah tersebut tetap BLOCKED sampai
