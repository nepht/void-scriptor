# Void Scriptor v1.2.0-rc.1 — Known Limits

Status: batas kandidat lokal. Daftar ini harus dibaca sebelum keputusan 112.53.

## Platform dan distribusi

- Bukti build utama saat ini adalah Windows lokal; matriks native lintas platform belum tersertifikasi.
- Installer MSI, upgrade/uninstall native, signing Authenticode, macOS notarization, dan mobile release signing belum dibuktikan.
- Hosted CI pada exact candidate SHA dan public publication belum dijalankan.

## Recovery dan hardware

- True hardware power loss dan USB cold-eject memerlukan pengujian fisik.
- Crash diagnostics dibuktikan melalui structured-log tests; dialog crash/recovery native belum diverifikasi.
- Downgrade database in-place tidak didukung. Jalur aman adalah backup, aplikasi kompatibel, atau ekspor yang didukung.

## UX, accessibility, dan localization

- Widget/contract tests mencakup keyboard, scaling, contrast state, reduced motion, locale, RTL data, dan multiscript.
- Native screen-reader certification, physical contrast measurement, native RTL mirroring, dan platform IME belum selesai.
- Profile-mode FrameTiming dan cold-start native belum direkam.

## Worldbuilding dan AI

- Wave 1 capabilities default OFF; sebagian Wave 2 memakai shared kill switch `vs12_world_logic_shared`, juga default OFF.
- Banyak gate world-logic adalah deterministic local/domain evidence; itu tidak membuktikan seluruh workflow native atau persistence untuk setiap modul.
- Provider AI eksternal, model availability, biaya, dan uptime tidak dijamin. Credential tidak boleh dimasukkan ke project.

## Release boundary

Dokumen dan test lokal mendukung evaluasi RC, bukan otomatis `GO`. Signed artifact, checksum/provenance final, hosted checks, residual-risk acceptance, dan persetujuan Choirudin tetap gate terpisah.
