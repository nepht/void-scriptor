# Void Scriptor v1.2.0-alpha.1 — Release Notes (Draft)

**Status:** alpha rehearsal documentation; not a signed release artifact.

## Highlights

- Story & Lore productivity: lore links, backlinks, contradiction analysis,
  mission board, quest dependencies, and unresolved subplot alerts.
- Clean export and deterministic export preflight.
- Cross-feature Novel–Character workspace links with explicit ownership and
  safe import/export behavior.
- Automated test matrix, performance benchmark infrastructure, and security/
  privacy verification.

## Compatibility and recovery

- Project data remains local-first.
- Upgrade rehearsal covers pre-migration backup, migration failure recovery, and
  rollback using a disposable copy.
- Do not upgrade the source project without creating a verified backup first.
- If migration fails, preserve the original source and restore only through the
  recovery flow.

## Privacy

- Reader/share output redacts protected content and drops internal metadata.
- Cross-workspace access requires explicit permissions and links.
- Do not place credentials in project content or manifests.
- External endpoint, encrypted-at-rest, and OS sandbox certification are not
  claimed by this alpha draft.

## Known limitations

- This document is not proof of a signed artifact.
- Version line, artifact checksum, and signature verification must be recorded
  only after the controlled alpha build completes.
- Performance results are development-only benchmarks, not production SLOs.
- E2E evidence is an in-process contract flow; native desktop and OS-level
  certification remain separate work.
- Native assistive-technology certification and physical display contrast
  measurement remain deferred.

## Feature flags

Wave 1 capabilities ship disabled by default. Explicit opt-in is required for
local validation; a flag being known does not imply it is enabled.

## Verification status

This draft is paired with local migration, rollback, feature-flag, security,
accessibility, and full-suite evidence in the Sprint 109 ledger. The final
release note must be amended with the exact artifact version, SHA-256, signing
verification result, and build command after those gates pass.
