gagal memilih device GPU pada VM tanpa GPU. Proses tetap hidup dan jendela
native muncul. Diklasifikasikan sebagai keterbatasan lingkungan uji
(ledger 107.24 PARTIAL), BUKAN crash produk, dan TIDAK masuk intake insiden.
