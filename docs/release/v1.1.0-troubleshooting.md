# VOID SCRIPTOR v1.1.0 — Troubleshooting

## Aplikasi tidak mau start setelah update project lama

1. Cari backup pra-migrasi `<nama>.db.bak` (atau serupa) di samping file DB
   project — migrasi selalu membuat backup dulu.
2. Jalankan ulang aplikasi; bila tetap gagal, buka issue dengan melampirkan
   versi (`Help → About` atau log startup) TANPA mengirim isi cerita.
3. Rollback data: restore backup (byte-for-byte, teruji 105.11).

## Project versi lebih baru menolak dibuka

Project format/schema yang tak dikenal DITOLAK dengan aman sesuai kontrak
C1/C2. Jangan paksa membukanya dengan build lama; perbarui aplikasi.

## Plugin ditandai incompatible / disabled_for_safety

Plugin API major beku di 1. Manifest major ≠1 → `rejectedApiVersion`;
capability tidak di-grant → `rejectedCapability`. Periksa preflight report;
tidak ada fallback senyap by design.

## Workflow berhenti di approval gate

Itu perilaku benar (human-in-the-loop, deny-by-default). Setelah deadline,
keputusan otomatis = DENY. Lanjutkan dengan keputusan eksplisit atau
perpanjang deadline di definisi workflow.

## Automation tidak jalan jaringan/eksternal

Jaringan keluar default-deny kecuali destination terdaftar; transfer AI/
publish butuh konfirmasi transfer. Ini fitur keamanan, bukan bug.

## Masalah lain

Buka issue di repo dengan template: issue_id, version, platform, severity,
reproduction, diagnostics (redacted). Lihat `docs/release/v1.1.0-known-issues.md`
sebelum melapor — KI-01…KI-04 sudah tercatat.
