# v1.1.0 Release Notes (STABLE)

Status: DIPUBLIKASIKAN untuk kanal stabil via **metadata promotion** dari
`1.1.0-rc.1` (artefak identik byte-per-byte, terverifikasi @HEAD `46e0426`).
Bahasa pada dokumen ini hanya mengklaim apa yang terbukti di ledger sprint.

## Highlights

- **Workflow Intelligence** (Sprint 103): workflow runner dengan checkpoint,
  resume, cancel yang aman; persistensi definisi & riwayat eksekusi di
  database project (schema v56); recovery/templates/audit/limits.
- **Automation** (Sprint 104): trigger 6 tipe (manual/schedule/projectEvent/
  assetEvent/jobEvent/pluginEvent) dengan registry kanonik fail-closed;
  condition engine deterministik **tanpa bahasa ekspresi**; approval gates
  human-in-the-loop dengan deny-by-default; idempotency, dedupe, saga dengan
  kompensasi eksplisit; observability identifier-only.
- **Hardening RC** (Sprint 105): matriks migrasi v1.0.x→v1.1 terverifikasi,
  rollback byte-for-byte, security & privacy audit terdokumentasi.

## Improvements

- Scheduler memakai offset timezone eksplisit dan next-run terkomputasi.
- UI Automation Center responsif (1280px & 390px), tahan text-scaling 2.0x.
- Import/export rule menolak payload ber-kunci secret-shaped secara fail-closed.

## Compatibility

- Project format: schema **16**, major **1** — project v1.0.x tetap terbuka.
- Database project: migrasi beruntun 53→54→55→56, semuanya ter-guard,
  backup pra-migrasi wajib sebelum upgrade.
- Plugin API: major **1** dibekukan; manifest major lain ditolak terlihat.

## Security

- Tidak ada eksekusi kode dari definisi workflow/rule.
- Secret hanya direferensikan sebagai kunci store; nilai tidak pernah masuk
  definition, log, export, atau diagnostics (`[REDACTED]`).
- Jaringan keluar default-deny kecuali destination terdaftar di allowlist.

## Migration

- Jalur didukung: fresh install, beta→RC, dan era-v1.0.x (schema 53) → v56.
- Kegagalan migrasi meninggalkan project asli utuh (rollback terverifikasi).

## Known Issues

- Signing artefak & SBOM produksi: NOT AVAILABLE (toolchain lokal tanpa infra
  penandatanganan) — konsisten sejak v1.0.1.
- Validasi platform resmi saat ini terbatas **Linux x64 (WSL)**; platform
  lain belum dieksekusi pada siklus RC ini.
- Installer/upgrade packaging belum dibangun; upgrade in-app via migrasi DB.
