# VOID SCRIPTOR v1.1.0 — Installation (stable)

## Prasyarat (Linux x64)

- Flutter 3.44.x + Dart SDK 3.12.x (toolchain yang dipakai build rc-1)
- Paket sistem: `clang cmake ninja-build pkg-config libgtk-3-dev`

## Instalasi dari sumber (satu-satunya jalur pada rilis ini)

```bash
git clone https://github.com/nepht/void-scriptor.git
cd void-scriptor
export PATH="$HOME/toolchain/flutter/bin:$PATH"
flutter pub get
flutter build linux --debug
./build/linux/x64/debug/bundle/void_scriptor
```

Verifikasi integritas biner:

```bash
sha256sum build/linux/x64/debug/bundle/void_scriptor
# harus cocok: e87e6580508c9e4bf83539836b5f261735cc2d502e79cc28acf17d6b7788d44c
```

Catatan jujur: installer grafis belum tersedia pada v1.1.0 (KI-04);
build mode debug adalah artefak yang diuji dan dipromosikan.
