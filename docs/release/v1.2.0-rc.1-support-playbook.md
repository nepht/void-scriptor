# Void Scriptor v1.2.0-rc.1 — Support Playbook

Status: runbook lokal untuk triage kandidat RC. Tidak menetapkan kanal support publik.

## Intake minimum

Catat tanpa data privat:

- versi aplikasi dan platform;
- langkah reproduksi dan hasil aktual;
- apakah project dapat dibuka read-only;
- kategori: startup/session, database/migration, backup/restore, import/export, media, performance, accessibility, atau provider eksternal;
- timestamp dan path log lokal yang telah direduksi/redacted.

Jangan meminta API key, password, token, private key, atau salinan project pengguna tanpa consent dan prosedur transfer yang disetujui.

## Severity

- P0: kehilangan/korupsi data yang dapat direproduksi, credential exposure, atau bypass boundary keamanan.
- P1: project tidak dapat dibuka atau core workflow terblokir tanpa workaround aman.
- P2: fungsi salah dengan workaround aman; tidak ada kehilangan data.
- P3: kosmetik, dokumentasi, atau friction non-blocking.

## Triage aman

1. Preserve source project dan buat salinan/backup sebelum eksperimen.
2. Reproduksi pada fixture disposable bila mungkin.
3. Jalankan integrity scan dan kumpulkan recovery log; jangan repair diam-diam.
4. Pisahkan product defect dari provider eksternal, hardware, permission OS, atau toolchain.
5. Untuk migration/recovery, ikuti `v1.2.0-rc.1-recovery-guide.md`.
6. Untuk security/privacy P0/P1, hentikan distribusi kandidat dan eskalasi ke product authority; jangan publikasikan detail eksploit.

## Handoff engineering

Sertakan exact commit/artifact identity bila tersedia, command dan exit code, focused reproduction, file/region owner, expected vs actual, serta apakah data yang digunakan disposable. Status harus salah satu VERIFIED, PARTIAL, BLOCKED, UNVERIFIABLE, MISSING, atau DEFERRED.

## Batas operasi

Support tidak boleh mereset lock, menghapus quarantine/journal, memodifikasi database dengan SQL manual, meminta credential, atau mengunggah project tanpa izin eksplisit. Release/push/deploy dan komunikasi eksternal tetap membutuhkan otorisasi Choirudin.
