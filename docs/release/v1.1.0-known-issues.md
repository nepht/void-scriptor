# v1.1 Known Issues (RC)

Format wajib: issue_id / affected_scope / impact / workaround /
planned_resolution. Tidak ada entri tanpa workaround aman.

## KI-01 — Artefak belum ditandatangani

- **affected_scope:** artefak rilis (executable + manifest)
- **impact:** penerima tidak bisa memverifikasi penanda tanganan kriptografis;
  integritas masih diverifikasi via SHA-256 di manifest
- **workaround:** verifikasi checksum SHA-256 pada
  `docs/release/v1.1.0-rc.1-artifact-manifest.md` sebelum menjalankan
- **planned_resolution:** infra signing (post-1.1)

## KI-02 — SBOM produksi belum tersedia

- **affected_scope:** rantai pasok
- **impact:** inventori dependensi tersedia (`flutter pub deps`), tetapi bukan
  SBOM format standar (SPDX/CycloneDX)
- **workaround:** gunakan `docs/release/v1.1.0-rc.1-dependency-inventory.txt`
  sebagai inventori manual; lisensi via `flutter pub pub --license`/pubspec
- **planned_resolution:** generator SBOM otomatis (post-1.1)

## KI-03 — Validasi platform terbatas Linux x64

- **affected_scope:** Windows/macOS/Web/Mobile
- **impact:** klaim dukungan platform lain tidak didukung bukti siklus ini
- **workaround:** jalankan dari sumber di platform lain; laporkan temuan ke
  blocker register
- **planned_resolution:** matriks platform lengkap sebelum GO untuk v1.1 GA

## KI-04 — Installer & packaging belum dibangun

- **affected_scope:** distribusi end-user
- **impact:** instalasi saat ini via build dari sumber
- **workaround:** ikuti panduan build repo; upgrade data tetap amani oleh
  jalur migrasi DB teruji
- **planned_resolution:** pipeline packaging MSI/deb (post-1.1)
