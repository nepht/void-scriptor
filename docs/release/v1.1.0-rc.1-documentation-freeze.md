## Aturan freeze

1. Tidak ada perubahan API publik modul `lib/automation/`, `lib/workflow/`,
   `lib/core/plugin/domain/` tanpa entri blocker register.
2. Perubahan dokumentasi hanya boleh mengoreksi ketidakakuratan faktual,
   bukan mendokumentasikan fitur baru.
3. Setiap koreksi pasca-freeze dicatat sebagai commit `release-fix:` dengan
   justifikasi satu kalimat.
