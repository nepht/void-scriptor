## Conditions and risks

`GO_WITH_DOCUMENTED_RISK` applies only to local/offline alpha evaluation (superseding alpha-1 by one cycle). It does not authorize push, tag, hosted publication, or production distribution.

Before public release, the following must be closed or explicitly accepted by the product authority:

1. hosted CI green on the exact candidate SHA;
2. production platform artifact matrix and native signing;
3. external endpoint/security operational review;
4. release retention and rollback operations;
5. final D-SCHEMA-01 decision (freeze v56 versus additive schema evolution);
6. native assistive-technology and physical contrast validation.

## Final gate statement

A push or tag must wait for a full v1.2.0 release gate (Step 110.50) and a subsequent release train running on a verified shadow build.
