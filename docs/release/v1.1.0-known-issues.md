## KI-01 — RESOLVED: Artefak kini bertanda tangan kriptografis

- **status:** CLOSED 2026-08-25 (offline, tanpa infrastruktur eksternal)
- **resolution:** RSA-3072 detached signature + sertifikat lokal
  `CN=Void Scriptor Local Code Signing` (valid s.d. 2036). Kunci privat
  disimpan DI LUAR repositori (`~/codesign/`, tidak pernah masuk git);
  kunci publik dipublikasikan di `docs/release/signatures/v1.1.0/codesign.pub`
  dan disertakan dalam paket distribusi. Verifikasi:
  `openssl dgst -sha256 -verify codesign.pub -signature void_scriptor.sig bundle/void_scriptor`
  → Verified OK (diuji ulang pada paket hasil ekstraksi).
- **catatan jujur:** ini self-signed certificate — bukan CA komersial;
  keamanannya setara trust-on-first-use terhadap fingerprint di atas.
- **sisa risiko:** fingerprint harus diverifikasi out-of-band oleh pihak
  ketiga; tidak ada timestamping RFC3161.

## KI-02 — RESOLVED: SBOM CycloneDX tersedia

- **status:** CLOSED 2026-08-25 (generator lokal dari pubspec.lock)
- **resolution:** `docs/release/v1.1.0-sbom.cdx.json` — CycloneDX 1.5,
  125 komponen dengan purl `pkg:pub/<name>@<version>`, termasuk hash
  SHA-256 aplikasi. Disertakan dalam paket distribusi sebagai `SBOM.cdx.json`.
- **catatan jujur:** mencakup dependensi Dart/Flutter pub; komponen native
  sistem (GTK dsb.) belum terinventarisasi dalam SBOM ini.

## KI-04 — PARTIAL RESOLVED: Distribusi end-user via paket portable

- **status:** PARTIALLY RESOLVED 2026-08-25
- **resolution:** paket portable `void_scriptor-v1.1.0-linux-x64-portable.zip`
