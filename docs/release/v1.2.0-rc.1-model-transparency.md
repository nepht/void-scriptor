# Void Scriptor v1.2.0-rc.1 — Model Transparency

Status: kontrak transparansi lokal untuk world-logic dan fitur berbantuan AI; bukan sertifikasi model/provider eksternal.

## World-logic models

Katalog transparansi di `lib/features/world_logic/domain/documentation_transparency.dart` memisahkan:

- feature guide: input, asumsi, dan sumber;
- model card: unit dan uncertainty;
- assumption guide: invariant yang dipakai;
- override guide: jalur override dan alasan yang wajib dicatat;
- recovery guide: jalur recovery yang idempotent;
- known limit: batas domain yang tidak boleh dipresentasikan sebagai fakta pasti.

Output simulasi/generator harus menyimpan seed/provenance yang relevan, memakai unit eksplisit, dan menampilkan uncertainty atau explanation ketika kontraknya menyediakan nilai tersebut. Replay deterministik berarti input+seed yang sama menghasilkan keluaran kontraktual yang sama; ini bukan klaim akurasi dunia nyata.

## AI-assisted features

- Fitur AI bersifat opt-in dan berada di belakang capability/feature flag.
- API key atau credential tidak disimpan dalam database project.
- Prompt/context harus berasal dari resolver/composer terstruktur, bukan pembacaan database ad-hoc oleh widget.
- Reference images dibatasi budget provider dan provenance-nya dipertahankan.
- Output AI adalah usulan; pengguna tetap pemilik keputusan canon dan harus meninjau hasil sebelum diterapkan.
- Provider eksternal, model availability, latency, harga, dan kebijakan data berada di luar jaminan local-first Void Scriptor.

## Yang tidak diklaim

Kandidat ini tidak mengklaim fairness certification, factuality guarantee, provider uptime, training-data provenance provider, atau evaluasi model eksternal menyeluruh. Native GUI disclosure dan provider-live behavior juga belum disertifikasi pada gate lokal ini.
